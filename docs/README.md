# Документация проекта

Этот раздел содержит проектную документацию для сайта-подарка `Моя маша`.

## Основные документы

- `superpowers/specs/2026-06-22-masha-love-site-design.md` — дизайн-спека (визуал, UX, анимации, требования к экранам)
- `superpowers/plans/2026-06-22-masha-love-site.md` — детальный пошаговый план реализации

## Что смотреть в первую очередь

1. Сначала дизайн-спеку (что и зачем строим).
2. Затем план (как именно реализовано по шагам).
3. После этого код в `src/screens`, `src/components`, `src/styles`.

## Актуальные точки настройки в коде

- `src/constants/config.ts` — дата, письмо, картинка, подписи, музыка
- `src/constants/words.ts` — слова для экрана с розой
- `src/store/useScreenStore.ts` — логика переходов между экранами
