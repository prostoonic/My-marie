# AGENTS.md

Инструкции для AI-агентов, работающих в этом репозитории.

## Цель проекта

Проект `Моя маша` — это одностраничный анимированный love-site на 7 экранов.
При изменениях важно сохранять атмосферу, плавность переходов и простоту поддержки.

## Обязательные правила

1. Не ломать последовательность экранов (`0..6`) и контракт `useScreenStore`.
2. Сохранять TypeScript-строгость: после изменений проект должен собираться без ошибок.
3. Не удалять пользовательские тексты/контент из `src/constants/config.ts` без причины.
4. Не добавлять тяжелые зависимости без явной необходимости.
5. Не менять поведение навигации между экранами без задачи от пользователя.

## Перед завершением задачи


```bash
npm run lint
```

Если есть тесты для затронутой области, также запустить:

```bash
npx vitest run
```

## Где обычно вносятся изменения

- `src/screens/*` — сценарий и визуал экранов
- `src/components/*` — общие компоненты
- `src/styles/*` — глобальные/модульные стили
- `src/constants/*` — контент и конфиг

## Формат изменений

- Делать минимально необходимый объем правок.
- Не смешивать в одном изменении рефакторинг и новую фичу, если это не требуется.
- Сохранять текущий стиль кода и именования.
